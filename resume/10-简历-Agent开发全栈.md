**阶段二 · 合规驱动的架构转型：桌面客户端**

- 因医疗数据不得出内网，**主导将 Web 版重构为桌面本地执行架构**：Electron（主 / 预加载 / 渲染三层隔离）+ React 19 + Vite，任务在用户本机 WSL2 内完成，数据不出网。安全基线关闭 `nodeIntegration`、开启 `contextIsolation` 与 `sandbox`，系统能力全部经预加载层 **IPC 白名单注册表**暴露。
- 自研 WSL2 一键装机链路（导入 Ubuntu rootfs → 创建 AgentScope 运行时 → 部署后端 → 健康检查），全程免管理员权限。定位并根治四个平台级缺陷：WSL 在最后一个会话结束时回收后台进程（改为主进程持有前台会话 + 指数退避守护）、Windows→`wsl.exe` 的 argv 传递破坏脚本内容（**改走 stdin 注入**）、uvicorn 仅绑 IPv4 而 Chromium 优先解析 `::1`、mirrored 网络模式需下发 Hyper-V 防火墙规则。**将一类「装完却连不上」的偶发故障收敛为可复现并彻底修复。**
- 实现数据脱敏全链路：任务执行前自动脱敏（Agent 只见脱敏数据），产物回传时按 token 映射还原为原值；跨文件令牌稳定、映射不进工作区不写日志、**fail-closed**。
- 本机重数据处理：DuckDB 对 csv/xlsx 跑只读 SQL，**百万行本机 0.28s**；大文件分块预览 + 组装内存上限，避免渲染进程 OOM。

**阶段三 · 组织管控服务端**

- 独立设计并实现组织服务端（FastAPI + SQLite，**4,200 行 / 41 个接口**）：邀请码注册、成员与角色、API Key 分发、工作流增量下发、WSL/AgentScope 镜像分发。因服务端面向多客户端并发写入，放弃客户端沿用的 JSON 存储，改用 **SQLite（WAL + `BEGIN IMMEDIATE`）消除读-改-写丢更新**。
- 将密钥分发从「共享企业 Key」重构为**池化按人分配**：幂等签出、离职回收、下发落审计（用户/设备/密钥三元组）、支持单独撤销 —— 解决共享凭据无法定位泄露源、无法按人撤销的根本缺陷。
- 设计**一机一凭据**的设备认证模型：装机时以注册令牌换取本机独有凭据（服务端仅存 PBKDF2 散列），可撤销单台设备而不影响其余装机；「被撤销设备不得自动重新注册」「已注册设备不得用自身凭据再注册新节点」两条关键约束均有测试守护。

**贯穿全程 · 稳定性与质量**

- 设计**恒温器式内存控制器**解决执行节点 OOM：以内核 `MemAvailable%` 与 PSI 为反馈量，通过 systemd **`MemoryHigh` 软限**逼网关回收而非杀进程；设加限/解限双阈值构成**迟滞带**、动作间强制稳定等待以抑制过冲与震荡，濒临 OOM 时批量紧急加限。上线后消除了执行机因单用户占用过高导致的整机不可用。
- 自研**零依赖 Go 并发压测工具**做容量评估：以 N 个互相独立账号模拟真实多人并发（而非单账号打 N 次）、登录与加压分离避免污染计时、调高 `MaxIdleConnsPerHost` 防止客户端先于服务端成为瓶颈、按成功请求统计延迟分位数并对错误分类；5 种负载模式用于定位各层并发拐点。
- 建立双端质量保障体系：**80 个单元测试 + 75 项端到端断言**（真实拉起两个进程，覆盖 HTTP 层超时、错误码、multipart 与 Range 语义），守护权限边界、越权拒绝、分片字节一致性、服务端不可达时不得降级绕过组织校验等关键性质。
- **主动开展安全审计并修复两处高危缺陷**：任务接口按 ID 访问缺归属校验（任意成员可读取/删除他人任务，含指令原文）；服务每次启动播种 `admin/admin` 默认管理员，并导致首个真实用户永远无法注册。均已修复并补回归测试。
